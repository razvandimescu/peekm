Read, review, and share what Claude Code did.

peekm turns every Claude Code session on your machine into something you can read: the conversation, each line it changed, and what it remembers about the project. It runs locally and needs no account.

$npx @peekm/peekm .
Homebrew, npm, Go and curl

Read

Every session from every project, in one timeline. Open one and read it as a conversation: your prompts, Claude's answers, each tool call and its thinking.

A session that is running now shows which tool Claude is using. The bar under each session shows its shape: green for new files, amber for edits, blue for commands.

Review

Each edit appears as a line diff, next to the message that explains it.

peekm also shows what Claude Code has saved to memory for each project. Those notes shape every future session in that project, and you can read all of them in one place.

Share

Share any file Claude wrote as a rendered page. One click gives you a link on your local network. A second click makes it public at share.peekm.dev for one hour.

The file stays on your machine. The relay only forwards requests while the link is live. Works with Markdown, HTML, SVG and plain text.

Install

npx
npx @peekm/peekm .
Homebrew
brew install razvandimescu/tap/peekm
npm
npm i -g @peekm/peekm
Go
go install github.com/razvandimescu/peekm@latest
curl
curl -L https://github.com/razvandimescu/peekm/releases/latest/download/peekm_$(uname -s)_$(uname -m).tar.gz | tar xz

Then run peekm ~/projects, or point it at any folder. It opens in your browser and sets up Claude Code tracking on the first run.
